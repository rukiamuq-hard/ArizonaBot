# ArizonaBot AI Auto Reply

## Работа программы

**Сообщения приходящие в Telegram:** [ТГ уведомления](https://mega.nz/file/0B8D1C5L#kwxi5T9iX8Am2XaJjpHljbS09PSbgHZU98RLkOkBlRk)

**Видео нету, потому что если админ начнёт вести переписку, ИИ не остановить :)**

ArizonaBot — программа на C++ для автоматического ответа администраторам в чате Arizona RP. Программа отслеживает изменения в `chatlog`, определяет сообщения от администрации, отправляет уведомление в Telegram и генерирует ответ через Gemini AI с последующей автоматической отправкой сообщения в игру.

Во время запуска программа автоматически определяет путь к игровым логам через папки пользователя Windows. Из найденных файлов выбирается самый новый лог чата.

После загрузки логов программа переходит в режим постоянного мониторинга файла. Каждая новая строка анализируется в реальном времени. Если в сообщении обнаруживается обращение администратора, программа отправляет уведомление в Telegram и передаёт текст сообщения в Gemini API.

Ответ от модели генерируется на основе содержимого `prompt.txt`. Полученный текст автоматически вставляется в игровой чат через эмуляцию клавиатуры с задержками между символами для более естественного ввода.

## Возможности

* Автоматический мониторинг `chatlog`
* Автоответчик на сообщения администрации
* Генерация ответов через Gemini AI
* Telegram-уведомления при новом сообщении
* Автоматический поиск пути к логам Arizona RP
* Имитация ручного ввода текста
* Работа в реальном времени без встроенных LUA-скриптов

## Отличия от прошлой версии

В прошлой версии программа работала как обычный автоответчик с заранее подготовленным текстом. Теперь ответы генерируются динамически через Gemini AI в зависимости от сообщения администратора и содержимого пользовательского промпта.

Добавлена работа с Google Gemini API через HTTP-запросы и JSON. Ответы больше не ограничены шаблонами и формируются отдельно для каждого нового сообщения.

Система уведомлений Telegram была переработана и теперь запускается в отдельном потоке, не блокируя основной мониторинг логов.

Также обновлён механизм поиска логов и выбора последнего активного `chatlog`.

## Настройка

Перед запуском необходимо создать файл `TokenChatId.txt`.

Формат файла:

```txt
TELEGRAM_BOT_TOKEN
CHAT_ID
GEMINI_API_KEY
```

### Получение Telegram Bot Token

Токен можно получить через Telegram-бота `@BotFather`.

### Получение Chat ID

Вставьте токен в ссылку:

```txt
https://api.telegram.org/botYOUR_TOKEN/getUpdates
```

После этого отправьте сообщение своему боту и откройте ссылку в браузере. В ответе будет указан ваш `chat_id`.

## Настройка prompt.txt

Файл `prompt.txt` используется как системный промпт для Gemini AI.

**Именно этот текст определяет стиль, поведение и формат ответов автоответчика, рекомендую поиграться с промптом для лучшей работы ИИ.**

## Запуск

После запуска программа автоматически найдёт путь к логам и начнёт мониторинг.

Если всё загружено успешно, в консоли появится сообщение:

```txt
Succesfully loaded log. Thank you for use!
```

## Важно

Программу необходимо запускать уже после входа в игровой аккаунт. Иначе может быть выбран старый лог-файл из предыдущих игровых сессий.
